# Проверки доработки от 27 сентября 2026 года

- Ruff: проверка правил и форматирования прошла для backend.
- mypy: ошибок в 14 модулях исходного кода нет.
- pytest в контейнере с PostgreSQL: 19 тестов прошли.
- Проверены два независимых API-процесса, восстановление подписки по курсору,
  изоляция исполнителей, переназначение, отзыв роли и активности, истечение JWT.
- Конкурентные одинаковые запросы создают одну заявку и одно уведомление.
  Из двух изменений одной версии проходит одно. Ошибка записи журнала откатывает заявку.
- В тестовой БД выполнены откат и повторное применение новой миграции;
  контрольная сумма пользователей, площадок, заявок, аудита и ключей повторов совпала.
- Frontend: линтер, TypeScript, форматирование изменённых файлов и сборка прошли.
- Полный Compose-стенд запущен; API, frontend и PostgreSQL прошли healthcheck.
  Runtime API использует UID 10001; порты доступны только на loopback.
- Diff проверен; известных форматов приватных ключей и служебных токенов в изменениях нет.

Визуальная браузерная проверка не выполнена: подключённый браузер недоступен.
Нагрузочные пределы, восстановление PostgreSQL из резервной копии и кластерная
отказоустойчивость не проверялись. Результаты не подтверждают production-эксплуатацию.

CI выполняет проверки для каждого коммита:
[GitHub Actions](https://github.com/dasferwer/fieldops-cloud/actions/workflows/ci.yml).
